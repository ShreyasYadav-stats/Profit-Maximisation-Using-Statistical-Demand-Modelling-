# Datasets

This folder contains the simulated datasets used throughout the project.

- **`newsvendor_clean_4stores.xlsx`** – Clean dataset generated from the simulation and ready for analysis.

- **`newsvendor_dirty_4stores.xlsx`** – Dirty version of the dataset containing deliberately introduced data quality issues,
including missing values, duplicate records, inconsistent date formats, non-numeric demand entries and unrealistic demand values.
